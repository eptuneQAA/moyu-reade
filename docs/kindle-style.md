# moyu Kindle 风格改版 — 设计

日期：2026-10-23
范围：只改阅读界面与配色，不改解析、搜索、进度、伪装逻辑。

## 1. 目标

把阅读页从“终端工具”改成“墨水屏书页”：

- 极简：默认显示页眉、正文、页脚和一行快捷键提示
- 纸张感：整屏铺底色，暖白纸或夜间墨色两套主题
- Kindle 排版：默认 72 列（约 36 汉字），TXT/EPUB 段首缩进两格
- 页码：底部细进度条 + `第 X 页 / 共 Y 页   42%`
- 顶部：书名 + 当前章节，小字，下面一条细横线

## 2. 主题

| 名称 | 背景 | 正文 | 次要文字 | 强调/进度 |
| --- | --- | --- | --- | --- |
| `paper` | `#f6f1e7` | `#3b352c` | `#8a7f6c` | `#8a5a2b`；轨道 `#d9cfbf` |
| `night` | `#1f1e1b` | `#d8d2c4` | `#8b8578` | `#c9a86a`；轨道 `#3a362f` |
| `opencode` | `#0f0f0f` | `#edecee` | `#6d6d6d` | `#a277ff`；轨道 `#2d2d2d` |

- 默认 `paper`
- 设置面板新增“主题”，左右切换立即生效并保存；顺序为 paper → night → opencode
- 阅读页和阅读页上的浮层（目录/搜索/设置/帮助）使用主题色
- 书架、伪装界面保持终端原色

## 3. 版式

```
书名                                      当前章节
──────────────────────────────────────────────

　　正文第一段。默认 72 列，居中，段首缩进两格。
　　第二段。

              ━━━━━━━━━━━━━─────────
          第 3 页 / 共 18 页   16%

```

- 页眉：左右分布，小字；`t` 可隐藏（隐藏后正文多两行）
- 分隔线：`─` 铺满正文宽度，次要色
- 正文：行宽 = `min(charsPerLine, 终端列数 - 2)`，整体居中
- 缩进：TXT/EPUB 的非空、非章节标题行加两个全角空格；PDF 不加
- 页脚：24 格进度条（`━` 填充、`─` 轨道）+ 页码/百分比；自动翻页时追加“自动翻页”
- `h` 可隐藏/显示完整快捷键提示（占一行，默认显示）

## 4. 分页

- 每页显示行数 = 终端行数 − 页眉/分隔线/间距/页脚占用（无快捷键提示时 6 行，有提示时 7 行；页眉隐藏时减 2）
- 总页数 = `ceil(显示行数 / 每页行数)`
- 页码 = `floor(当前页首行 / 每页行数) + 1`
- 自动翻页和 `Space` 都按整页前进，最后一页从 `(总页数-1) * 每页行数` 开始，页码与总页数一致

## 5. 配置变化

```json
{
  "charsPerLine": 72,
  "showFooter": true,
  "theme": "paper"
}
```

- 旧配置缺 `theme` 时默认 `paper`
- 旧配置已保存的 `charsPerLine` 不强制迁移
- `showFooter` 默认 `true`，按 `h` 可隐藏提示

## 6. 改动文件

- `src/ui/theme.js`：新增 `THEMES` 和 `themeOf()`
- `src/ui/Reader.jsx`：重写为 Kindle 版式
- `src/core/paginate.js` + `src/core/book.js`：`buildRows/layout` 支持段首缩进（保持 offset 映射）
- `src/ui/App.jsx`：主题背景、页码、整页对齐、页数计算、浮层传主题色
- `src/ui/Settings.jsx`：新增主题行
- `src/config.js`、`src/core/settings.js`：默认值与主题切换
- `test/settings.test.js`、`test/paginate.test.js`：补充主题切换和缩进测试

## 7. 验收

1. 打开 TXT/EPUB，页面呈现暖白纸背景、页眉、细进度条和页码
2. 设置切到 `night` 后立即变成深色，重启后保持
3. 默认 72 列，约 36 汉字/行，段首缩进两格
4. 翻页后页码递增，最后一页显示 `第 N 页 / 共 N 页`
5. `t` 隐藏页眉后正文多两行；`h` 显示/隐藏快捷键提示
6. PDF 不缩进，翻页、搜索、进度、伪装不受影响
7. 全部测试（当前 40 个）通过
